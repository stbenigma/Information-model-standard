# im-standard-schema
The definition of the information model structure. as json-schema

This is (almost) the original of the standard information model definition.
It is the source to validate a Information-model-json file.

It is derived (manually maintained) from the information model model in dataspot and in the sql database.


## GeneralDefinitions
Defininitons of elements used in different places

## InformationModel
Definitions of the elements of the information model

## ModelValidation
testmodels to verify the schema-definitions

Python module to validate the run a validation of any model-schema and of all the test-schema-definitions
