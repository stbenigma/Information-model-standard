ATTRIBUTES

Description of the container of a value. Also known as a property or characteristic.
The attribute is the valid single source of truth for values in the conceptual model.

According to the first normal form (1NF) of the relational model, an attribute value makes a statement about ONE aspect of ONE instance of the entity for which the attribute is a property. This means that multi-value attributes and combined attribute values are not permitted.

The ‘repeated’, ‘historicised’ and ‘translated’ flags indicate multi-value attributes for special purposes. This is not a contradiction to 1NF, as these indicators and their meaning enable an algorithmic transformation into a 1NF model.

Is either directly an attribute for an entity (entity attribute) or is an attribute/field in a group attribute (domain attribute).

Examples
Name
Date of birth
Geo-location
Longitude

DOMAINS

Description of the value range of one (or more) attribute(s).
It describes which technically relevant values a particular attribute may assume.
The technical data type and display formats are defined in the implementation (software, databases) and are not of interest here.

Group value ranges are several attributes that occur together. They are summarised under a new name for easier handling. Example: Telephone no. consisting of country code and telephone number. For the entity, the entire group is seen as one attribute, as the values belonging together must always occur together.

Value lists are value ranges in which all permitted values are shown in a list.

Examples
Mountain name, 1-100 characters
Mailadress, ^[\w-\.]+@([\w-]+\.)+[\w-]{2,4}$
Integer 1..100
Length, in mm, numeric(7,3)
Processing status (open, in progress, cancelled, completed)
Geo coordinate (longitude, latitude)

INFORMATION_MODELS

An information model describes the relevant things (entities), their properties (attributes) and relationships in a target environment (shpere of influence). It defines the names to be used in communication as well as the meaning and purpose they have in this environment.
Thanks to its mathematical basis (relational model), it provides a verifiable model that describes all possible true statements (facts/predicates in the sense of predicate logic) for the environment.
For the management of knowledge in the form of data, the information model provides the exact description of the information requirements as well as the desired interpretation of the data content for its use

RELATIONS

A relationship always connects one entity (start entity) with exactly one second entity (end/reverse entity).

The two ends can link an entity to themselves. This is called a recursive relationship. It typically represents a hierarchy. The two ends of a recursive relationship must be optional.

A distinction is made between 3 types of relationship.

Functional relationships
form a clear mapping from the first to the second entity. This means that there is a relationship from one instance of the first entity to a maximum of 1 instance of the second entity. (or none for optional relationships).

Role relationship
form a specialisation of an entity. Roles of an entity *are* the entity supplemented by additional relationships or attributes. This means that roles always inherit all the properties of the entity of which they are a role and extend them with properties that are necessary for their use.

Many-to-many relationships
An instance of one side can be related to many instances of the other side. And vice versa.
This type of relationship is not provided for in the relational model and must be resolved in the technical implementation by means of an additional entity/table. This resolution is clearly defined algorithmically so that the many-to-many relationship does not violate the rules of the relational model.
The relationship makes sense for the information model, as it represents a fact in a simpler and therefore more readable way.

Examples
A planet orbits a star. - A star is orbited by 0 - many planets.
A bus is a means of transport. - A means of transport can be a bus.
A train is a means of transport - A means of transport can be a train.
A customer bought 0 - many products. - A product can be bought by 0 - many customers.
