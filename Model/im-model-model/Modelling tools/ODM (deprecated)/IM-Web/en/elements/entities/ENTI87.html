Entity

Domain

Description of the allowed values of one or several attribute(s).
The types numerical, text, time or enumeration are to be understood conceptually.
Real data types and, if applicable, display formats and storage are defined in the implementation.

Value groups are attribute groups, i.e. several attributes that occur more than once together. They are combined under a new name for ease of handling.

List of Values (LOVs) are explicit enumerations of all allowed values.
