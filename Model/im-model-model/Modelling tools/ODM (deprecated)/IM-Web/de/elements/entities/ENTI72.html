Beziehungsende

*Endpunkt einer Beziehung. Anknüpfungspunkt der Relation an eine Entität.
Es gibt immer genau 2 Endpunkte in einer Relation.
Es gibt eine Richtung der Beziehung: vorwärts/rückwärts
Zur Vereinfachung der Verwendung der verschiedenen Arten der Beziehung Rolle, funktional, viele-2-viele verwenden spezifische Beziehung endet als vorwärts und rückwärts.

Die Beziehung ist wie folgt zu lesen:
1 Instanz der Entität <1/viele> Instanzen der Entität am anderen Ende der Relation.

Name Relation End
Synonym
Beschreibung End point of a relationship. Connection point of the relation to an entity. There are always exactly 2 end points in a relation. There is a direction of the relationship: forward / reverse For ease of use the different types of the relation role, functional, many-2-many use specific relationship ends as forward and backward. The relationship is to be read as follows 1 instance of the entity <association-text> <optional/mandatory> <1/many> instances of the entity at the other end of the relation.
Beispiele An address must be in a postcode area.
A postcode area can contain many addresses.
A bus optionally travels several routes.
A route is optionally travelled by many buses.
