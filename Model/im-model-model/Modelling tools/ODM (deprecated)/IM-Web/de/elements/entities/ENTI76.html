Entität

*Bezeichnet eine Sache von Interesse in diesem Einflussbereich (Zielumgebung). Ein Wesen, ein materielles oder immaterielles (abstraktes) Objekt mit Eigenschaften und Beziehungen.
Es handelt sich um eine konsolidierte Beschreibung der Struktur und Bedeutung der Sache von Interesse. Die Beschreibung ist unabhängig von der Verwendung dieser Entität in Geschäfts- oder IT-Prozessen. Sie ist ferner unabhängig von jeder Art der Implementierung als Daten oder Programmcode in einem beliebigen IT-System.
Ein Entitätsname ist in der betrachteten Umgebung eindeutig. Die Definition der Entität (Attribute, Beschreibung, Regeln, Beziehungen, ...) ist die einzig gültige Interpretation, die mit ihrem Namen ausgedrückt wird.

Synonym
Beschreibung Designates a thing of interest in this shere of influence (targetenvironment). A being, a tangible or intangible (abstract) object with properties and relationships. It is a consolidated description of the structure and meaning of the thing of interest. The description is independent and not aware of the usage of this entity in business- or IT-processes. It is further independent of any kind of implementation as data or program code in any kind of IT-system. An entity name is unique in the considered environment. The definition of the entity (attributes, description, rules, relationships,...) is the only valid interpretation expressed with this name.
