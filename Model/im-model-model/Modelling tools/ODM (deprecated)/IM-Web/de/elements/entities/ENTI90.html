Beschreibung Values that describe a point in time. The accuracy of the value (from millisecond to year) is determined by the granularity (millisecond, second, minute, hour, day, week, month, quarter, half-year, year). Neither the storage nor the representation of the point in time is part of the information model. This is handled in the database or UI specification.
