Entität

Attribut

Beschreibung des Behälters eines Wertes. Auch Eigenschaft oder Merkmal genannt.
Das Attribut ist die gültige Single Source of Truth für Werte im Begriffsmodell.

Nach der ersten Normalform (1NF) des relationalen Modells macht ein Attributwert eine Aussage über EINEN Aspekt EINER Instanz der Entität, für die das Attribut eine Eigenschaft ist. Dies bedeutet, dass mehrwertige Attribute und kombinierte Attributwerte nicht zulässig sind.

Die Flags „repeated“ „historicised“ und „translated“ kennzeichnen mehrwertige Attribute für besondere Zwecke. Dies ist kein Widerspruch zur 1NF, da diese Indikatoren und ihre Bedeutung eine algorithmische Transformation in ein 1NF-Modell ermöglichen.

Ist entweder direkt ein Attribut für eine Entität (Entity-Attribut) oder ist ein Attribut/Feld in einem Gruppenattribut (Domain-Attribut).

Beschreibung Description of the container of a value. Also known as a property or characteristic. The attribute is the valid single source of truth for values in the conceptual model. According to the first normal form (1NF) of the relational model, an attribute value makes a statement about ONE aspect of ONE instance of the entity for which the attribute is a property. This means that multi-value attributes and combined attribute values are not permitted. The ‘repeated’, ‘historicised’ and ‘translated’ flags indicate multi-value attributes for special purposes. This is not a contradiction to 1NF, as these indicators and their meaning enable an algorithmic transformation into a 1NF model. Is either directly an attribute for an entity (entity attribute) or is an attribute/field in a group attribute (domain attribute). Examples Name Date of birth Geo-location Longitude
