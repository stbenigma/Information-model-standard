# ODM (Oracle Data modeler)

The first modelled version of the Information model was done in Oracle data modeler.

It is free software from Oracle, which still runs.

This is the original definition but was migrated (and improved) to dataspot.
It is put here as a historical artefact.

In this version we generated a HTML-representation of the model.
see IM-Web/de/index.html or IM-Web/en/index.html

THIS MODEL IS DEPRECATED.
