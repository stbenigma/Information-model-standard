# dataspot

The actual version of the Information model is modelled in dataspot.
(www.dataspot.at).
The files in the directory IM-Stand-2026-06 are the dataspot export of the currently published elements.

All other representations of the model are generated with python programs out of this export.
(Excepction: the jseon-schema definitions, see Model/im-json-schema/ were done and are maintained manually)
