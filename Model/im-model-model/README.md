# Model/im-model-model.json

The information model of the Information model.

**im-model-model.json**
json file expressing the information model model. According to its' own meta definition InformationModel-schema.json

**im-model-model.db**
sqlite database file containing the information model model. The structure is built with its own meta schema in im-standard-ddl.sqlite.sql 

## Modelling tools
### ODM 
version of the first modelled information model model in Oracle data modeler. DEPRECATED

###dataspot 
version of the actual Information model.
Still maintained in dataspot.
Together with a datamodel of the information model model as represented in the sqlite db file.
