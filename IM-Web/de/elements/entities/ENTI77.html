Entitätsschlüssel

*Liste von Schlüsseln, die alle dazu dienen, eine Instanz dieser Entität in der Realität zu identifizieren.
Ein Schlüssel besteht aus einem oder mehreren Attributen und funktionalen Beziehungen, deren Werte in Kombination eine eindeutige Gesamtinstanz darstellen. Es kann eine beliebige Anzahl von Schlüsseln für eine Entität geben.
Schlüssel sollten nach Möglichkeit natürliche Schlüssel sein. D.h. Eigenschaften, die in der Realität vorkommen. Künstliche Schlüssel helfen nicht dabei, eine Instanz einer Sache in der realen Welt zu finden.

Beschreibung List of keys, all of which serve to identify one instance of this entity in reality. A key consist of one or several attributes and functional relationships, whose values in combination are unequivocal overall instances. There may be any number of keys for one entity. Keys should be natural keys wherever possible. I.e. properties occuring in reality. Artificial keys do not help to find an instance of a thing in the real world.
