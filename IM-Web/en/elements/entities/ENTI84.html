Element de
Name Rollenbeziehung
Synonym
Description *1:1 Beziehung die eine Rolle darstellt. Analogon: Ein:e Schauspieler:in (Person) spielt eine Rolle um eine andere Person (mit anderen Merkmalen) zu repräsentieren. Eine Rolle hat immer eine Grundentität, die sie erweitert. Ein physikalischer Artikel ist ein Artikel mit Abmessungen und Gewicht. Alle Eigenschaften (Attribute, Beziehungen, Schlüssel, Regeln,... ) der Grundentität gelten auch für die Rolle. Die Rolle *ist* die Grundentität, erweitert umd eigene Eigenschaften, für spezielle Nutzungen. Eine spezielle Art von Rolle sind exklusive / "entweder-oder" Rollen sog. Subentitäten. Eine Gruppe von exkusiven Rollen wird in einem Arc zusammengefasst. Die Grundentität (in dem Fall genannt Superentität) muss genau eine der Rollen aus der Gruppe annehmen. Bsp: Ein öffentliches Verkehrsmittel ist entweder ein Bus oder ein Zug oder ein Schiff. Bei Rollenbeziehungen sind die Kardinalitäten auf beiden Seiten "1". Die Beziehung von der Rolle zur Grundentität ist obligatorisch, von der Grundentität zur Rolle ist optional. Bei Subentitäten ist die Beziehung der Subentität zur Grundentität (Superentität) immer obligatorisch, von der Superentität zur Grundentität ist die Beziehunge obligatorisch und in einem "entweder-oder", d.h. in einem Arc zusammengefasst. Der Assoziationstext ist immer "ist". Darum wäre der Text redundant und er kann zu Gunsten der Einfachheit, weggelassen werden.
Examples Ein Arbeitnehmer ist eine Person - eine Person kann ein Arbeitnehmer sein.
Ein Mieter ist eine Person - eine Person kann ein Mieter sein.

Ein Zug ist ein öffentliches Verkehrsmittel
