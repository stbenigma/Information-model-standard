# Information model Standard

## Documents
Generated or assembled documents describing the Information model Standard or the Information model as such.

 
## Example models
Some informtion model serving as exanples

## Model
The actual source for the definition of a standard for the description of Information models.

### im-standard-schema
json-schema definition of the information model.

### im-model-model
The information model itself, represented as an information model in different languages
- im-model-model.json: the information model provided as a json-file according to the im-standard definition
- im-model.model.db: sq1lite-database containing the information model
- im-standard-sql: a sql-script defining the database to contain an information model
- Modelling tools: exports of definition in a modelling-tools
